桂木なお編：エンディング一覧

序盤のいくつかの選択肢が、のちのちのエンディング分岐に影響するので、注意。

  • 船の夜で、ウェイターを引き受けるか断るか。
    （断った場合、第２の殺人時にバッドエンドになる）
  • ウェイターを断って、アイスピックを盗んでいるか。
    （第２の殺人で、行動によってはエンディング分岐）
  • 船の夜に、玲香に話しかけて「芸能ライターがいる」を選択しているか。
    （第２の殺人で、行動によっては２通りに分岐）
  • 島１日目で、内線電話を調べているか。
    （声明文の解明時、行動によっては２通りに分岐）

喫茶店

No.01 | ランク D | 「オ」
夜中にインターフォンが鳴り、孝志に殺される。

  • 電車で「ヌード写真集」を選択している → 喫茶店で、「もしかしたら…パート３」。
  • コーヒーを飲み終えた後、喫茶店を途中で出る → 雨の中、ひたすら家に帰る。
    ※電車で「ヌード写真集」を選択していた場合、選択肢なしでインターフォンに出る。
    ※「ヌード写真集」を選択していなかった場合、選択肢が出て、インターフォンに出なかった場合、夢オチで喫茶店に戻る。

船の夜

No.02 | ランク D | 「ー」
バーに行く途中で、ちはる達と話す → 「イヤミを言う」 → 「シェーッ！」 → ふざけた選択肢を取り続ける → バラドルになる → 夜中にインターフォンが鳴り、孝志に殺される。
No.03 | ランク F | 「プ」
ちえを疑い、船でちはる達と話さない → バーでウェイターを断る → アイスピックを盗む → ちえをアイスピックで刺して殺そうとする。
No.04 | ランク H | 「ニ」
ちえを疑い、船でちはる達と話さない → バーでウェイターをして、玲香に話しかける → 部屋で玲香を疑う → 玲香を殺そうとする。
No.05 | ランク E | 「ン」
ちえを疑い、船でちはる達と話さない → バーでウェイターを断る → 氷を選択し、アイスピックを盗まない → ちえの首を締めて殺そうとする。
No.06 | ランク D | 「グ」
「シェーッ！」 → 「バケラッタ！」 → 「これ以上ふざけている場合ではない」 → 包帯の男を見て、「歌月に出会ったのか」 → 伸也の姿を見るまで進めて、「伸也君が生き返った」 → 「いや、たぶんできないだろう…」 → オタクアイドルになり、ゲーム会社の社長になる → 矢追つとむに殺される。

船での朝

No.07 | ランク F | 「の」
コーヒーに毒を入れる → 逃げようとする。
No.08 | ランク E | 「ム」
コーヒーに毒を入れる → 平然を装う。

明子の殺害

No.09 | ランク C | 「ー」
島２日目の朝、コーヒーポットのそそぎ口に毒を塗って、明子を殺害し、罪を認める。
No.10 | ランク D | 「ビ」
島２日目の朝、コーヒーポットのそそぎ口に毒を塗って、明子を殺害し、シラを切ろうとするが、青酸カリが見つかって捕まる。
No.11 | ランク E | 「ー」
シャワーブースで明子を殺害したが、捕まる。
  • 明子の殺害時に、シャワーブースの選択を間違えていた。
  • 明子の殺害後、シャワーブースから逃げる時のゲームで見つかっていた。
No.12 | ランク C | 「再」
船の夜に、バーでウェイターを断っている。
シャワーブースで明子を殺害後、見られずに逃げる → 金田一に寝ぼけて抱きつかれた時に、女だとばれていた。
No.13 | ランク D | 「生」
製氷皿に毒を入れる → 殺害後、合鍵を取りに行く時に、自分の部屋に寄って製氷皿を持っていく → 製氷皿を落として見つかる。

正彦の殺害

No.14 | ランク E | 「中」
アリバイトリック → 正彦の部屋に行く時に、幸夫に見つかった → 「大理石の時計」 → 金田一が部屋に来る → 「えっ、いつですか？」 → 時計が犯行時刻で止まっていた。
No.15 | ランク D | 「に」
アリバイトリック → 計画時に、「証拠インメツ」 → 正彦の部屋に行く時に、幸夫に見つからなかった → 「大理石の時計」 → 金田一が部屋に来る → 「えっ、いつですか？」 → スシを持ってきたスタッフに見られていた。
No.16 | ランク D | 「、」
船の夜に、玲香に話しかけていない、または「芸能ライターがいる」を選択していない場合。
アリバイトリック → 正彦の部屋に行く時に、幸夫に見つかった → 「大理石の時計」 → 金田一が部屋に来る → 「ええ、その時なら…」 → 犯行時刻を勘違いして、食い違った証言をしてしまう。
No.17 | ランク C | 「Ｒ」
船の夜にウェイターを引き受け、「玲香に話しかける」 → 「芸能ライターがいる」 を選択している場合。
No.16 と同じ手順。
No.18 | ランク E | 「と」
密室トリック（客室）→ 明子の部屋の合鍵をフロントに取りに行くゲームで、支配人に見つかる。
No.19 | ランク C | 「上」
密室（重い物を落とす） → 大理石の時計を落とすゲームで失敗する。
No.20 | ランク D | 「と」
密室（重い物を落とす） → 大理石の時計を落とすゲームで成功 → 「いや、私がやった証拠はない」。
No.21 | ランク B | 「ス」
密室（重い物を落とす） → 大理石の時計を落とすゲームで成功 → 「今のうちに逃げ出そう」。
No.22 | ランク C | 「タ」
密室（しめ殺す） → 「幸夫に罪をかぶせる」 → 幸夫に変装 → 首を締めるのに成功する。
No.23 | ランク C | 「ー」
密室（しめ殺す） → 「幸夫に罪をかぶせる」 → 幸夫に変装 → 首を締めるのに失敗する。
No.24 | ランク D | 「ト」
２日目の昼食時に、「いいえ」を選択して、金田一達と食べず、孝志と会話している。
密室（しめ殺す） → 幸夫に罪をかぶせず、変装せずに実行 → 首を締めるのに成功して、２階に引き上げる → 孝志になおであることを感付かれていた。
No.25 | ランク C | 「ボ」
密室（しめ殺す） → 幸夫に罪をかぶせず、変装せずに実行 → 首を締めるのに成功して、２階に引き上げる → 「こっそりフロントへ合カギを戻しにいく」 → 合鍵が見つかる。
No.26 | ランク B | 「タ」
  • 密室（しめ殺す）→ 幸夫に罪をかぶせず、変装せずに実行 → 首を締めるのに失敗する。
  • 密室（倉庫）→ ロープを引くゲームで失敗する。
No.27 | ランク C | 「ン」
密室（しめ殺す） → 幸夫に罪をかぶせず、変装せずに実行 → 首を締めるのに成功して、２階に引き上げる → 「いったん自分の部屋へ戻る」 → 一度解散した後、「金田一を生かしておいては危険だ」。
No.28 | ランク C | 「を」
密室（しめ殺す） → 幸夫に罪をかぶせず、変装せずに実行 → 首を締めるのに成功して、２階に引き上げる → 「いったん自分の部屋へ戻る」 → 一度解散した後、「金田一がどこまでわかっているかさぐってみよう」 → 翌日、見破られる。
No.29 | ランク B | 「押」
船でウェイターを断ってアイスピックを盗み、明子を氷で毒殺して、製氷皿を持たずに合鍵を取りに行っている。
No.28 と同じ手順。
※明子を正しいルートで殺害した場合、ウェイターを断ったルートでは、金田一に抱きつかれて、No.12 になってしまうので、氷で毒殺する必要がある。
No.30 | ランク D | 「す」
２日目の朝の片付け時に、倉庫を調べて、「ピンホールカメラの原理」 を選択し、隣の部屋に入っている。
計画時に「密室トリック」で「カギのかかる部屋なら、どんな部屋でも」 → 倉庫を殺害現場にする → 準備を終えた後、「内線電話で正彦を呼び出す」 → 部屋に剣持が来る。

声明文

「つとむを殺す」と「つとむを利用する」の選択肢は、複数の手順で到達が可能。

No.31 | ランク F | 「と」
孝志を銃で殺そうとして、逆に撃たれる。
「見当がついていた」 → 「つとむを利用する」 → 「ちはるに気をとられている」 → 「凶器を取り出した」。
No.32 | ランク B | 「ミ」
銃を使わずに、矢追つとむか孝志を殺そうとして、なおの姿で部屋を出て、見つかる。
  • 「誰が書いたんだ」 → 「犯行がつらくなった」 → 「つとむを殺す」 → 「なおの姿の方が」
  • 「見当がついていた」 → 「つとむを利用する」 → 「なおに気をとられている」 → 「すべての事件をなおの仕業に」 → 「なおの姿で孝志を殺す」
No.33 | ランク C | 「ー」
「見当がついていた」 → 「つとむを利用する」 → 「ちはるに気をとられている」 → 「孝志の様子をさぐる」 → 「体温計に毒をぬる」 → 幸夫に、体温計を持ってきた所を見られていた。
No.34 | ランク C | 「ュ」
No.33 の流れで、体温計に毒を塗らない → 孝志になおだとバレて殺される。
No.35 | ランク D | 「ジ」
「誰が書いたんだ」 → 「犯行がつらくなった」 → 「つとむを殺す」 → 「いや、それは危険だ」 → 男の姿で会いに行き、殴られて崖で心中。
No.36 | ランク C | 「ッ」
「つとむを利用する」 → 「なおに気をとられている」 → 「すべての事件をなおの仕業に」 → 「いや、それは危険だ」 → 声明文を書く → 「消化器で孝志に殴りかかる」。
No.37 | ランク C | 「ク」
No.36 の流れで、体温計を取りに行く → 体温計に毒を塗らない。
No.38 | ランク C | 「テ」
No.36 の流れで、体温計を取りに行く → 体温計に毒を塗る → 誤って幸夫が死に、孝志と爆弾で心中。
No.39 | ランク B | 「ス」
島１日目に、内線電話を調べていない場合。
「見当がついていた」 → 「めんどうなことになる」 → 「どうして彼はあんな声明文を書いたのか」 → 「かばおうとしている」 → 電話で孝志の殺害を頼む → 電話の録音を聞かされる。
No.40 | ランク Z | 「ト」
島１日目に、内線電話を調べていること。
No.39 と同じ手順で、電話で孝志の殺害を頼む → 金田一とちはるの警護をする → （ここの選択肢は影響なし） → 電話の対策を取られていた。
No.41 | ランク LOVE | 「モ」
「見当がついていた」 → 「めんどうなことになる」 → 「やめさせる」 → 「彼がどこまで知っているというんだ」。

第３の殺人

No.42 | ランク B | 「ー」
なおであることをバラさなかった場合、足の組み方で女だとばれる。
  • 正彦の殺害時に、アリバイトリック → 幸夫に見られてない → 「時計」の場合は、バラす選択肢が出ない。
  • 「いや、まだわかりませんよ」または「いや、それは危険すぎる！」を選択した場合、バラさない。
No.43 | ランク B | 「ド」
正彦を、密室トリック・倉庫で殺害していた場合（直接呼びに行った場合）。
なおであることをバラさない → 倉庫のトリックが見破られた上で、足の組み方でばれる。
（なおであることをバラせば、クリアできます）
No.44 | ランク B | 「に」
玲香の部屋に行かない → 孝志を内線電話で呼び出す → 直後に金田一達にばれる。
No.45 | ランク B | 「な」
玲香の部屋に行かない → アリバイで、タイトルを正解 → 電話のトリックを見破られて、自殺。
No.46 | ランク B | 「り」
玲香の部屋に行く → アリバイで、タイトルを間違う。
No.47 | ランク B | 「ま」
玲香の部屋に行く → 孝志を内線電話で呼び出す → 直後に金田一達にばれる。
No.48 | ランク B | 「す」
玲香の部屋に行く → 孝志を携帯電話で呼び出す → 孝志が来るまで待つ → 狙撃ゲームに失敗。
No.49 | ランク B | 「。」
玲香の部屋に行く → 孝志を携帯電話で呼び出す → 港で、途中で帰る → 孝志に殺される。
No.50 | ランク B | 「以上」
玲香の部屋に行かない → アリバイで、タイトルを間違う。
暗号を並べると、「オープニングのムービー再生中に、Ｒと上とスタートボタンを押すとミュージックテストモードになります。以上」。
※No.33 と No.34 の文字が逆になっています。
